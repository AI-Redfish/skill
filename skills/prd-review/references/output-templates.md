# prd-review 输出模板（按需加载）

三种模式的标准输出结构。生成报告时按所选模式读取对应模板，
保存到约定目录的 Markdown 与 HTML 文件，自查和校验后立即用默认浏览器打开 HTML。

## 输出模板

### A. `文档梳理模式`

使用以下结构输出，保存到约定目录的 Markdown 与 HTML 文件，自查和校验后立即用默认浏览器打开 HTML：

# PRD 梳理文档

## 需求概览
- 目标与对象：一句话说明服务谁、解决什么问题。
- 主要流程：用短句串起入口、核心动作和结果，适合时附简图。
- 关键逻辑与结果：只说明影响主流程的核心规则，不重复后文详情。

## 1. 分析范围
- 输入来源：
- 分析范围：仅当前材料 / 当前材料 + 全部相关 PRD 材料 / 用户指定范围
- 完整材料获取方式：`modao-prd-links` / 页面侧边菜单 / 用户补充链接 / 用户补充附件 / 直接读取文件 / 混合方式
- `modao-prd-links` 执行结果：未使用 / 成功 / 失败 / 部分成功
- 已分析模块：
- 无法访问或未确认内容：
- 会议纪要：已提供（来源/时间）/ 未提供（用户表示没有或选择跳过）
- 结论适用范围：基于当前可见页面 / 基于当前文件内容 / 基于 CLI 枚举到的完整链接集合 / 受限于部分内容缺失 / 未结合会议纪要
