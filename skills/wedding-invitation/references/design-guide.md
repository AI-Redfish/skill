# 动森请柬视觉规范（design-guide）

供修改模板 `scripts/templates/acnh.html` 或为用户定制时参考。

## 配色（CSS 变量）

| 变量 | 值 | 用途 |
|---|---|---|
| --cream | #FFF6DC | 页面底色 |
| --green / --green-d | #7BC86C / #5AA84E | 护照头、绿色按钮 |
| --ticket / --ticket-d | #F7B32B / #E09A18 | 里程票券主体 |
| --brown / --brown-l | #6B4F35 / #8A6D50 | 正文/次级文字 |
| --blue | #8ED3F0 | 地图海面 |
| --pink | #F9C6D0 | 花瓣点缀 |

## 七页结构与动效

| 页 | 组件 | 动效 |
|---|---|---|
| P0 启动页 | SVG 叶子 logo + 主按钮 | 叶子 bob 浮动 |
| P1 里程票 | 票券(两侧半圆缺口+虚线撕票线) | sway 轻摆 |
| P2 岛民护照×2 | 头像圆框+信息行(身份/岛屿/性格/最爱) | fadeup |
| P3 对话气泡 | 白气泡+底部三角、打字机逐字、点击跳过 | 光标闪烁、逐字 tick 音 |
| P4 婚礼信息 | 日期卡+实时倒计时+SVG 小岛地图+高德导航/复制地址 | 每秒刷新 |
| P5 相册×3 | 纯 CSS 插画(春樱/夏海/秋阳) | 花瓣飘落 |
| P6 结尾 | 心跳 emoji + 日期姓名 | beat 脉动 |

## 交互与音频（页面内置，无需外部资源）

- BGM：WebAudio 实时合成（108bpm C 大调五声音阶，木琴+三角波贝斯+hi-hat 循环）
- 按钮/翻页「哔」音、打字 tick 音、右上角音乐开关（🔇 可静音）
- 翻页：上滑/点击箭头/键盘；内容超高页面滚动到底/顶才翻页（防误触）
- 复制地址：clipboard API + execCommand 降级

## 文案模板（P3 打字机，generate_h5.py 自动填充）

> 亲爱的岛民：/ 攒了好久的里数，/ 终于换到两张婚礼门票啦 ✈️ /
> {日期} · {星期} / 请空出这一天，/ 带上好心情登岛 🏝️ /
> 我们在【{场地}】/ 等你一起见证重要时刻！/ —— {新郎} & {新娘}

## 照片替换（P5 相册）

把 `.photo.ph-*` 整块替换为：

```html
<div class="photo" style="background:url(照片.jpg) center/cover"></div>
```

照片与 HTML 放同一目录（保持单文件可分享可改用绝对 URL）。

## 护照人设默认值

| 字段 | 新郎 | 新娘 |
|---|---|---|
| 头像 | 🐻 | 🐰 |
| 性格 | 悠闲型 | 元气型 |
| 最爱 | 向日葵 🌻 | 桃子罐头 🍑 |

均可通过 `--groom-avatar` / `--bride-avatar` / `--config` 覆盖。
