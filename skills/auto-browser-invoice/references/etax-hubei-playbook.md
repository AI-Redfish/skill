## 已确认信息【确认】

- 首页 URL：`https://etax.hubei.chinatax.gov.cn:8443/`（全国统一规范电子税务局-湖北）
- 页头右上角：橙红色「登录」按钮（登录入口）；旁边有「环境检测」「电子税务局APP下载」
  「公众服务」「办税指南」「办税日历」入口
- 页头下方有「办税日历」公告条（如：11月申报期限顺延至11月16日）
- 动态 WAF：无 JS 直连返回 HTTP 412（2025-11 实测）→ 一切操作必须在真实浏览器内

## 登录流程【已确认，2025-11 实测】

1. 首页右上角点「登录」→ 跳转登录页（etax_login.py 自动完成此步）
   - 登录页 URL：`https://tpass.hubei.chinatax.gov.cn:8443/#/login?redirect_uri=…`（独立 tpass 子域，hash 路由）
2. 登录页分**三个身份标签页**：企业业务（默认选中）/ 自然人业务 / 代理业务；
   另有「特定主体登录」「非居民企业登录」入口
3. 两种方式人工完成登录（脚本绝不代填）：
   - 左侧：电子税务局 APP 扫二维码
   - 右侧（企业业务示例）：统一社会信用代码/纳税人识别号 + 居民身份证号/手机号/用户名
     + 个人用户密码 + 蓝色「登录」按钮（可能触发短信验证）
4. 登录成功跳回 etax 主站，右上角显示纳税人名称与退出入口（登录态判定依据之一）

## 开票路径【待验证——首次执行流程 B 时回填】

- 预期路径：我要办税 → 发票使用 → 蓝字发票开具（数电票）
- 抬头要素：名称、统一社会信用代码、地址电话、开户行及账号（专票必填后两项）
- 首次执行时：逐步截图 → 确认菜单名/控件位置 → 回填本节 → 更新 SKILL.md 路线图状态

## 发票下载【待验证】

- 预期路径：税务数字账户 → 发票查询统计 → 全量发票查询 → 下载 PDF/OFD
- 下载必须走浏览器下载事件（`expect_download` + `download.save_as`），
  禁止 API 直拉（WAF 动态 Cookie 不在，依旧 412）

## 故障与风速对照

| 现象 | 判定 | 处理 |
|---|---|---|
| 页面空白/内容与税务局无关 | WAF 质询页 | 等 3–5 秒自动放行；reload 一次；仍不行截图给用户 |
| 滑块/图形验证码/短信验证 | 风控验证 | 一律人工完成，脚本只等待，禁止绕过 |
| 提示环境检测失败 | 浏览器环境异常 | 确认是真实 Chrome 而非 Playwright 自启；检查有无自动化标记残留 |
| 登录态频繁失效 | profile 被清/多端挤下线 | 检查 profiles/chrome 是否被误删；避免多地登录同一账号 |
| 登录页打不开/点击登录无反应 | 浏览器窗口过小，元素折出视口 | human.py 会报错并提示最大化窗口；启动已内置 --start-maximized，勿手动改小窗口 |
| 菜单/按钮找不到 | 站点改版 | 截图给用户确认后更新本文（沉淀闭环），勿盲试 |
