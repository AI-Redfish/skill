# 需求增强：从模糊想法到结构化设计简报

> 改造自 Stitch 官方 enhance-prompt / design-mappings / prompt-keywords 方法论。
> 用途：生成页面前，把用户口语化描述增强为结构化设计简报，保证一次生成质量。
> 该步骤在内部完成（思考或草稿），简报本身不落盘，除非用户要求查看。

## 五要素评估（逐项核对用户输入，缺啥补啥）

| 要素 | 核对点 | 缺失时 |
|---|---|---|
| 平台 | Web / 移动端 App / 小程序 | 从上下文推断；推断不出且影响结构时问（一次一问） |
| 页面类型 | 落地页 / 仪表盘 / 列表 / 表单 / 详情 / App 首页 | 从描述推断 |
| 信息结构 | 有哪些区块、区块顺序 | 按 UI 惯例组织合理结构 |
| 视觉风格 | 气质关键词、明暗、密度 | 读 DESIGN.md；无则按项目气质推荐一档 |
| 数据 | 真实数据 / 可接受示例数据 | 用有机感示例数据并交付标注 |

## 模糊词 → 专业术语映射（写简报时替换）

| 模糊表达 | 专业表述 |
|---|---|
| 顶上一个菜单 | sticky 顶部导航栏（logo + 菜单项 + 主操作按钮） |
| 大图 | 通栏 hero 区，焦点图 + 大标题 + 主 CTA |
| 一堆东西列表 | 响应式卡片网格（hover 微抬升）或缩略图列表 |
| 按钮 | 主操作按钮（强调色填充 + 按压缩放微交互） |
| 表单 | 带标签输入、校验态与提交按钮的表单区 |
| 图片位 | hero 区焦点图 / 卡片头图（内联 SVG 或 CSS 图形占位） |
| 侧边栏 | 可折叠侧导航（图标+文字对，激活态高亮） |
| 弹窗 | 模态对话框（遮罩 + 居中卡片 + 明确主次操作） |
| 好看一点 | （具体化为气质组合，见下方风格档位表） |
| 数据看板 | 指标卡行 + 趋势图 + 明细表的三层仪表盘结构 |

## 风格档位速查（气质关键词 → 设计描述）

| 用户说法 | 设计描述 |
|---|---|
| 现代简洁 | 干净、大留白、高对比排版、克制的强调色 |
| 专业商务 | 沉稳可信、细描边、低饱和受限色板、结构化层级 |
| 活泼年轻 | 高饱和点缀、大圆角、有弹性的微动效、友好语气 |
| 高端奢华 | 大留白、细线条、强对比标题、精致阴影、编辑摄影感 |
| 暗黑科技 | 深底（非纯黑）+ 高对比强调色 + 数据发光点缀 |
| 温暖自然 | 暖中性底、有机圆角、纹理感、亲和插画式图形 |
| 后台系统 | 高密度、信息层级清晰、低装饰、状态色系统完整 |

## 结构化简报输出格式（内部使用）

```
[一句话：页面目的 + 气质]

设计系统：引用 DESIGN.md（第 2/3/4 节关键 token 摘录）
页面结构：
1. [区块名]：[内容与组件描述，用专业术语]
2. [区块名]：[...]
数据：[区块级示例数据说明，标注哪些是示例]
```

定点修改场景（调整模式）格式：

```
改动点：[一句话]
位置：[具体区块]
样式：[颜色/圆角/尺寸具体值]
范围：只做这一处改动，保留其余全部
```

## 组件关键词表（写简报与 HTML 时用准确术语）

- **导航**：导航栏 / 面包屑 / 标签页 / 侧边栏 / 抽屉菜单 / 底部标签栏（App）
- **容器**：hero 区 / 卡片网格 / 模态对话框 / 手风琴折叠 / 轮播
- **表单**：文本输入 / 下拉选择 / 开关 / 日期选择器 / 搜索框 / 步骤条
- **反馈**：toast 通知 / 警告条 / 骨架屏 / 进度条 / 空态
- **形状语言**：pill 全圆角 / 柔和大圆角 / 锐利直角；glassmorphism 半透明模糊（慎用，需深色底）
- **层次**：flat 无阴影 / whisper-soft 漫射淡阴影 / floating 高悬浮阴影
