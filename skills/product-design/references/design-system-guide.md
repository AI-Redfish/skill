# 设计系统方法论（DESIGN.md 撰写指南）

> 本指南改造自 Google Stitch 官方 taste-design / design-md 方法论，适配中文产品原型与离线 HTML 场景。
> DESIGN.md 是所有页面的唯一视觉基准：先定刻度，再写九节；改规范只改这里。

## 四档刻度（写 DESIGN.md 前先在内部定档，写进第 0 节）

| 刻度 | 1-3 | 4-7 | 8-10 | 默认建议 |
|---|---|---|---|---|
| 创造力 Creativity | 极简瑞士、安静、单色 | 平衡干净但有个性 | 编辑风、大胆排版实验、强非对称 | 7 |
| 密度 Density | 画廊式大留白 | 平衡分区 | 驾驶舱式高密数据 | 5 |
| 变化 Variance | 对称可预测 | 微错位 | 艺术化、无两个相同区块 | 6 |
| 动效 Motion | 静态克制 | 流畅 CSS 微交互 | 电影级编排 | 5 |

后台管理系统类默认降创造力（3-5）提密度（6-8）；品牌官网/活动页相反。

## 1. 视觉主题与氛围
用两三句"有画面感"的话定调，禁空词（"现代、美观"）。写法示例：
> 克制、画廊式的界面，自信的非对称布局，流动的弹簧动效。像一间采光良好的建筑事务所：每个元素靠功能赢得位置。整体印象：贵气、有意图、有生命感。

## 2. 色板与角色
每个颜色三件套：**语义名（#hex）— 功能角色**。
- 底色用暖中性（如 #F9FAFB 画布白），不用冷蓝白
- 主文字 Off-Black（#18181B 即 Zinc-950），**禁纯黑 #000000**
- 次要文字（#71717A）、三级文字/时间戳/禁用态（#94A3B8）
- 卡片描边半透明（rgba(226,232,240,0.5)），阴影大而淡（0 20px 40px -15px rgba(0,0,0,0.05)）
- **主强调色只选 1 个**，饱和度 <80%，按项目气质选：翡翠绿 #10B981（增长/数据）/ 电光蓝 #3B82F6（效率/SaaS/开发者）/ 深玫红 #E11D48（创意/编辑/时尚）/ 琥珀 #F59E0B（社区/社交/温暖）
- 深色主题：深底用 Zinc-950/#0B0F19 级别，强调色对比度拉高，禁大面积纯黑面板

## 3. 字体规则（中文环境适配，重要）
- **中文 UI 一律系统栈**（离线硬要求，禁 Google Fonts 外链）：
  `-apple-system, "PingFang SC", "HarmonyOS Sans SC", "MiSans", "HarmonyOS Sans", "Microsoft YaHei", "Noto Sans SC", sans-serif`
- 英文与数字可指定西文字体名（系统有则生效，无则回退）：Geist / Outfit / Cabinet Grotesk / Satoshi；**禁 Inter 做品牌标题，禁 Times New Roman/Georgia 类默认衬线**
- 层级用字重与字号驱动（标题 700-900，正文 400），标题字距收紧（-0.02em），行高：标题 1.15 / 正文 1.65、正文最大宽度 65ch
- 字号：展示标题 `clamp(2rem, 5vw, 3.5rem)`，正文 ≥15px 移动端、16px 桌面端；数据仪表盘数字用等宽（"Geist Mono", "JetBrains Mono", ui-monospace, Consolas）
- 中文注意：行高比英文略高（1.7-1.8 更舒展）；禁用楷体/宋体做软件 UI 正文

## 4. 组件规范（每类写清形状+颜色+行为）
- **按钮**：平面无外发光；主按钮强调色填充白字，次按钮描边/幽灵；按压 `scale(0.98)` 或 `-1px` 位移；hover 微移背景色，**禁 glow**
- **卡片**：大圆角（16-24px，创造力 8+ 可到 32px）、白面、半透明描边、漫射阴影；内边距 24-32px；高密布局用分隔线/留白替代卡片堆叠
- **输入框**：label 在上，错误信息在下（深玫红），焦点环强调色 2px offset；禁浮动 label
- **导航**：桌面横向、sticky、间距充裕；移动端全屏抽屉/底部 tab（App 界面）
- **加载**：骨架屏微光（与真实布局同形状同圆角），**禁圆形转圈 spinner**
- **空态**：插画/图标组合 + 引导文案 + 行动按钮，禁只写"暂无数据"
- **错误态**：行内上下文提示 + 明确恢复动作

## 5. 布局原则
- 结构布局一律 CSS Grid，**禁 flexbox 百分比拼凑**（`calc(33% - 1rem)` 禁用）
- **禁三等分一排卡片**的功能区：用 2 列之字（Zig-Zag）、不对称 Bento（如 2fr 1fr 1fr）、横向滚动画廊
- 内容最大宽 1400px 居中，水平留白 16/32/64px（移动/平板/桌面）
- 整页高度用 `min-height: 100dvh`，**禁 `height: 100vh`**（iOS 地址栏跳动）
- 元素间**禁止重叠**：文字永不压在图片/文字上，各占各的栅格位
- 变化档 ≥8 时：Hero 禁居中对称，用 50/50 分屏、左文右图或大留白不对称
- CTA 克制：主 CTA ≤1 个，禁标题下再塞"了解更多"链接

## 6. 响应式规则（硬要求，生成后必须自查三档）
- 移动端 (<768px)：多列一律塌缩单列、宽度 100%、内边距 16px、间距 24px
- **禁横向滚动**：任何元素超视口宽即设计失败
- 断点验证基准：375（iPhone SE）/ 768（iPad）/ 1440（桌面）；移动端原型另验 390
- 触控目标 ≥44px；移动端按钮通栏全宽
- 字号 clamp() 平滑缩放；正文最小 14px
- 用 screenshot.py 截三视口逐一核对（无浏览器时提醒用户自行打开核对）

## 7. 动效与交互
- 只动 `transform` 和 `opacity`，**禁动 top/left/width/height**（性能红线）
- 弹簧物理：`stiffness: 100, damping: 20`，禁 linear easing
- 列表/网格级联入场：`animation-delay: calc(var(--index) * 100ms)`
- 常驻微动效：状态点呼吸、加载微光、图标浮动；仪表盘每个活跃组件给一个循环态
- 动效档 ≤3 时只保留 hover 反馈与骨架屏

## 8. 图标与图像（离线硬要求）
- 图标一律**内联 SVG**（24px 栅格、stroke 1.5-2px、currentColor），**禁 emoji 当图标**
- 占位图/配图：纯 CSS 渐变 + 网格纹理、内联 SVG 图形、几何构图；**禁外链图片**（Unsplash/picsum 断网即裂图）
- 头像用内联 SVG 首字母圆形色块

## 9. 反模式清单（生成每页后逐条自检）
**颜色**：纯黑 #000000 / 紫色霓虹渐变（"AI 紫"）/ 饱和度 >80% 的强调色 / 混用冷暖两套灰
**字体**：Inter 做标题 / 默认衬线（Times/Georgia）做 UI / 字重层级单一
**布局**：三等分卡片一排 / 居中对称 Hero（高变化档）/ 元素重叠 / calc 百分比栅格 / 100vh
**组件**：圆形 spinner / glow 外发光 / 浮动 label / z-index 滥用（仅导航/弹层可用）
**文案**：Lorem ipsum / "Scroll to explore""向下滚动探索"类填充文案 / AI 陈词滥调（赋能、极致体验、颠覆式、引领未来、Elevate、Seamless、Unleash、Next-Gen）/ `LABEL // 2024` 式装饰排版
**数据**：编造统计指标（"99.99% 正常运行""124ms 平均响应"——用户未提供即禁止，改用 `[指标]` 占位或有机示例数据如 47.2% 并在交付时标注）/ 整数派假数据（99%、1234567）/ 假名（张三、李四、test123、John Doe）/ "系统性能指标"式编造数据卡片
**杂项**：emoji 当图标 / 破图外链 / 自定义鼠标指针 / 大标题渐变文字滥用
