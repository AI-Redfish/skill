# BrowserSkill（腾讯）

> GitHub：https://github.com/Tencent/BrowserSkill（MIT，5.5k+ stars）

腾讯开源的浏览器自动化技能，让 AI Agent 通过 `bsk` CLI 直接使用你**已登录的真实浏览器**。支持 pi、Cursor、Claude Code、Codex、CodeBuddy、DeepSeek Harness 等任何能调用 shell 的 Agent。

Agent 的任务在独立的 **Agent Window** 中执行，你在旁边照常用浏览器。要用你已打开的标签页必须显式"借用"，用完归还，其余不碰。

链路：Agent → bsk CLI → 本地 daemon（IPC）→ 浏览器扩展（WebSocket 127.0.0.1）→ Agent Window。

## 安装

### 1. 安装 CLI

```bash
# Windows（PowerShell，装到 ~\.local\bin）
irm https://raw.githubusercontent.com/Tencent/BrowserSkill/main/install.ps1 | iex

# macOS / Linux（装到 ~/.local/bin）
curl -fsSL https://raw.githubusercontent.com/Tencent/BrowserSkill/main/install.sh | sh
export PATH="${BSK_INSTALL_DIR:-$HOME/.local/bin}:$PATH"
```

验证：`bsk --version`

### 2. 安装浏览器扩展

| 浏览器    | 地址                                                         |
| :-------- | :----------------------------------------------------------- |
| Chrome    | https://chromewebstore.google.com/detail/hhcmgoofomhgciiibhipgmgkgnoenaoi |
| Edge      | https://microsoftedge.microsoft.com/addons/detail/browserskill/emacgiaaaiojkkpkddmmdfhmokgmnikg |

装好后打开扩展弹窗，确认显示已连接（默认连本地 daemon，无需改端口）。

### 3. 安装 Skill

```bash
bsk install-skill                 # 交互式：空格选择 harness，回车安装
bsk install-skill --list --json   # 查看支持的 harness 与安装路径
bsk install-skill --harness pi --json   # 非交互指定
```

未列出的 harness 手动安装：把仓库 `skill/SKILL.md` 复制到技能目录，如 pi 项目级 `.pi/skills/browser-skill/SKILL.md`。

### 4. 验证

```bash
bsk doctor
```

每项 fail 都带 hint，照做后重跑。刚装完只挂"extension connected"属正常（还没装扩展）。

## 命令表格

| 命令                                | 功能           | 说明                                                         |
| :---------------------------------- | :------------- | :----------------------------------------------------------- |
| bsk session start --json            | 启动会话       | 创建 Agent Window，返回 session_id；--no-focus 不抢占焦点     |
| bsk session stop <id>               | 结束会话       | 任务结束（含失败）必须执行；同时归还借用的标签页              |
| bsk session list                    | 会话列表       | 查看当前活跃会话                                             |
| bsk navigate <url>                  | 导航           | 返回 reached=load 等加载状态                                  |
| bsk observe                         | 读取页面       | 输出无障碍树，元素带 @eN 引用；交互前先观察                   |
| bsk click @eN                       | 点击           | 点击引用元素                                                 |
| bsk fill @eN --value "文本"         | 填写           | 向输入框填充文本                                              |
| bsk press Enter --ref @eN           | 按键           | 在元素上按键（Enter / Tab 等）                               |
| bsk hover @eN                       | 悬停           | 展开悬停菜单                                                 |
| bsk scroll-to @eN                   | 滚动到元素     | 把元素滚入可视区                                              |
| bsk wheel --delta-y 600             | 滚轮           | 页面上下滚动                                                 |
| bsk screenshot                      | 截图           | --out 指定文件；--full-page 整页长图；--ref @eN 元素级        |
| bsk tab list --scope user           | 列出标签页     | 查看你（用户）已打开的标签页                                  |
| bsk tab borrow <id> / tab return    | 借用/归还      | 借用你已打开的标签页，默认需确认                              |
| bsk request-help                    | 请求人工接管   | 验证码、扫码登录、人脸确认等人工步骤                          |
| bsk browsers                        | 浏览器列表     | 多浏览器时配合 --browser <id> 选择                           |
| bsk status                          | 状态           | daemon、已连接浏览器、活跃会话（--json 可解析）               |
| bsk doctor                          | 诊断           | 健康检查，逐项给出 ok / FAIL 与 hint                          |
| bsk update --yes                    | 更新           | CLI 与 daemon 自更新；扩展走浏览器商店                        |
| bsk install-skill                   | 安装技能       | 把 SKILL.md 装入 Agent harness                               |

除 session stop 外，所有会话内命令都要带 `--session <id>`。

## 会话工作流

标准流程：明确目标 → `session start` → `navigate` → `observe` 拿 @eN 引用 → click / fill / press 交互 → `session stop` 收尾。

> 导航和大范围 DOM 变化会使已有的 @eN 引用失效，每次交互前先重新 observe。
>
> 不要依赖空闲清理来结束会话，也不要用重启 daemon 代替 session stop。

页面文字优先用 observe 读取；大页面用 `--cursor <token>` 分页观察。日常使用直接对 Agent 说自然语言即可，如"打开 github.com 并总结 README"。

## 标签页借用

Agent 只能操作 Agent Window 内的页面。要操作你已打开的标签页：

```bash
bsk tab list --scope user --session <id>   # 找到目标标签页
bsk tab borrow <tab-id> --session <id>     # 借用（默认弹确认）
bsk tab return <tab-id> --session <id>     # 用完归还，标签页保持打开
```

遇到验证码、登录、确认弹窗等人工步骤，Agent 发起 `request-help` 请求你接管；你在浏览器里完成后，Agent 继续执行。

## 安全设置

扩展弹窗里两个独立开关，保存在浏览器配置中，对现有和新建会话都生效：

| 开关                           | 默认 | 开启时                     | 关闭时                       |
| :----------------------------- | :--- | :------------------------- | :--------------------------- |
| Confirm before borrowing tabs  | 开   | 借用标签页前需要确认       | 直接借用（无人值守）         |
| Allow requests for human help  | 开   | 可弹窗请求人工接管         | help 请求返回 disabled       |

> 0.3.0 起 `--unattended`、`tab borrow --no-confirm`、`BSK_REQUEST_HELP=off` 已废弃，不能再绕过这两个开关，只能改扩展设置。

## 使用注意

| 注意点     | 说明                                                                                     |
| :--------- | :--------------------------------------------------------------------------------------- |
| 文件路径   | --out 等参数传给 bsk 的是 Windows 程序，必须用 Windows 路径（D:\...），/mnt/d/... 会报错  |
| WSL 调用   | daemon 是 Windows 进程；WSL 内命令挂起时改用 powershell.exe -Command "bsk ..."，或先 daemon start |
| 版本匹配   | CLI、daemon、扩展三者版本需一致（bsk status 查看），长截图等新功能依赖新版                 |
| 环境要求   | Windows x64 / macOS / Linux（x64、ARM64）；Chrome 或 Edge，Firefox 计划中                 |
| 登录态     | Agent Window 与你的浏览器同配置文件，已登录站点直接可用                                   |
| 收尾       | 每个任务结束都要 session stop，它同时负责归还借用的标签页                                 |
