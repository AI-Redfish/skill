

# 发布前检查清单

## 基本检查清单

| 检查项 | 检查内容 |
|---|---|
| 功能完整 | 所有计划功能已实现并测试 |
| 错误处理 | 常见错误场景均有处理和提示 |
| Description 准确 | 触发测试通过率 ≥ 85% |
| 依赖已声明 | requirements.txt 或 compatibility 字段完整 |
| 无硬编码密钥 | 脚本中无 API Key、密码等敏感信息 |
| 版本号已更新 | frontmatter 中 version 已更新 |
| CHANGELOG 已更新 | 本次变更已记录 |
| 调试代码已清除 | 无临时 print、调试检查点、TODO |



## 编写用户文档

在 SKILL.md 末尾或 README.md 中提供：

- **这个 Skill 能做什么**：具体列出自动完成的工作
- **快速开始**：三步内说清怎么用
- **系统要求**：Python 版本、依赖
- **常见问题**：文件太大、编码问题等



# 打包为 .skill 文件

特定平台通过.skill文件上传和安装skill，一般不用考虑这一步。

```bash
# 基础打包
python -m scripts.package_skill my-skill/

# 指定输出路径和版本号
python -m scripts.package_skill my-skill/ \
  --output dist/my-skill-v1.2.0.skill --version 1.2.0

# 验证包内容
python -m scripts.package_skill --list dist/my-skill-v1.2.0.skill
```

**批量打包脚本**

```bash
#!/bin/bash
set -e
for skill_dir in skills/*/; do
    skill_name=$(basename "$skill_dir")
    python -m scripts.package_skill "$skill_dir" \
      --output "dist/${skill_name}.skill"
done
```



# 发布到Git仓库

## 仓库结构

推荐将所有团队 Skill 放在同一个 Git 仓库中，用目录隔离不同 Skill：

```
skills-repo/
├── README.md                  # 仓库总览，列出所有 Skill
├── .github/workflows/package.yml   # CI：自动打包 .skill 文件
├── skills/
│   ├── data-analyzer/         # 各 Skill 目录
│   ├── doc-generator/
│   └── code-reviewer/
├── dist/                      # 打包好的 .skill 文件
└── tools/build_all.sh         # 批量打包脚本
```

## GitHub Actions 自动化打包

推送 main 分支时自动打包并上传构建产物：

```yaml
name: 打包并发布 Skills
on:
  push: { branches: [main] }
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with: { python-version: "3.11" }
      - run: pip install -r tools/requirements.txt
      - run: bash tools/build_all.sh
      - uses: actions/upload-artifact@v4
        with: { name: skill-packages, path: "dist/*.skill", retention-days: 30 }
```
