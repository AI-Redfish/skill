# Skills 简介

> 来源：[runoob Skills 教程](https://www.runoob.com/skills/skills-tutorial.html) / [Skills 简介](https://www.runoob.com/skills/skills-intro.html) + 原有笔记整合

## 一、什么是 Skills

Skill 封装了**指令、脚本及相关资源**，用于为智能体（Agent）提供可复用、面向特定场景的专业能力。

- Skill 可以被视为提供给智能体的一套 **"专业能力说明书"**（类似用户手册或操作指南 / 公司的 SOP 手册）
- 在执行任务时，智能体可以**按需加载**相应的技能，增强对任务的理解与执行能力
- 技术上是一个 Markdown 文件（SKILL.md），写着该任务的完整执行指南，由人类编写、被智能体自动读取并遵循

```text
智能体的大模型 = 大脑（负责理解、决策、说话）
Skills        = 手和脚（负责动手干活）
```

普通 AI 和 AI 智能体的核心区别：智能体不只是**思考者**，更是**行动者**。

| 你问 | 聊天机器人 | 智能体 |
|---|---|---|
| 今天北京天气怎么样？ | 猜一个答案 | 真的调用天气接口，给出真实结果 |
| 帮我查上月销售额 | 抱歉无法访问数据库 | 真的查数据库拉数据 |
| 帮我订去上海的高铁票 | 建议你去 12306 订票 | 真的打开 12306 查票、选座、下单 |

### 智能体的三个核心能力

| 能力 | 说明 | 例子 |
|---|---|---|
| 感知 | 接收输入，理解上下文 | 读取文件、理解需求 |
| 推理 | 制定计划，决定做什么 | 判断"先读文件，再生成报告，最后发邮件" |
| 行动 | 调用工具，执行步骤 | 真正打开文件、写内容、发出去 |

## 二、Skills 能解决什么问题

**没有 Skill 时**：Agent 反复问同样的澄清问题、错过团队命名规范、忘记边界情况；让 Claude 生成 Word 文档，它只输出 Markdown 文本而非真正的 .docx。

**有了 Skill 后**：自动识别任务 → 触发 docx Skill → 读取 Skill 了解正确的库和输出路径 → 生成真正的 .docx 文件。

核心价值三点：

1. **让智能体从会聊天变成会干活**
2. **可复用的经验包**：一次写入，所有人所有次调用结果稳定一致
3. **人与 AI 协作的桥梁**：人类专注定义怎么做，AI 负责真正去做

| 概念 | 一句话总结 |
|---|---|
| AI 智能体 | 能感知、推理、行动的 AI 系统，不只会聊天，还能执行任务 |
| Skills | 告诉智能体"如何完成某类任务"的说明书（Markdown 文件） |
| Skills 的价值 | 让任务执行变得准确、稳定、可复用 |

### Skills 的核心特性

- **自动触发**：AI 根据任务自动加载相关技能，无需手动输入长提示
- **可复用 & 可共享**：一次创建，全团队使用，支持 Git 版本控制
- **高效利用上下文**：渐进式披露（progressive disclosure），只加载需要的部分
- **跨平台**：Claude Code、VS Code Copilot、Cursor、OpenAI Codex 等通用

### 典型使用场景

- 领域专业知识：法律审查、数据分析、代码规范等封装成技能
- 工作流程：多步骤任务流程固化为可重复技能
- 公司规范：代码规范、提交流程、文档模板
- 工具集成：封装特定工具的使用方法和 API 调用

## 三、Skills 与 MCP 的区别

> Skills 用于**知识复用**，MCP 用于**能力扩展**。

| 维度 | Skills | MCP |
|---|---|---|
| 定位 | 知识复用（经验、最佳实践、工作流） | 功能扩展（连接 API、数据库、外部工具） |
| 创建门槛 | 基于 Markdown 文件，任何人可创建 | 需要编码能力和服务器端配置 |
| 加载方式 | 渐进式加载，Token 效率高 | 启动时加载全部工具定义 |
| 基础设施 | 无需服务器或后端 | 需要服务器/后端 |
| Token 消耗与复杂度 | 低 | 更高 |

**选择建议**：如果确定相同功能 Skill 和 MCP 都可以实现，**优先使用 MCP**（反应更快，适合调用具体工具或服务）；Skill 更适合需要引导 AI 执行复杂、多步骤工作流的场景。

## 四、调用 Skills 的方式

- **隐式调用**：直接用自然语言描述任务，如"帮我设计一个登录页面的 UI"，AI 自动匹配并调用 `frontend-design` 技能
- **显式调用**：
  - 方式 1（部分 IDE）：输入 `/` 列出可用技能命令，选择触发
  - 方式 2：明确说"请使用 XXX skill，帮我 XXX"

## 五、支持 Agent Skills 的工具

Agent Skills 是开放标准：Claude Code、OpenCode、GitHub Copilot、OpenAI Codex 等均支持，一次编写多处使用。
