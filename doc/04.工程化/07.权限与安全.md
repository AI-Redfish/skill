# 权限与安全控制

> 来源：[Skills 权限与安全控制](https://www.runoob.com/skills/skills-security.html)

## 一、默认权限范围（最小权限原则）

| 操作类型 | 权限状态 | 说明 |
|---|---|---|
| 读取上传文件 | 允许 | 仅限上传目录 |
| 写入输出文件 | 允许 | 仅限输出目录和工作目录 |
| 读取系统文件 | 受限 | 只读挂载 |
| 访问外部网络 | 受限 | 仅白名单域名 |
| 执行任意系统命令 | 受限 | 不能 sudo、不能改系统配置 |
| 访问其他用户数据 | 禁止 | 沙箱隔离 |

> Skill 只能访问它明确需要的资源。需要超出上述范围的权限时，应重新考虑设计方案。

## 二、在 SKILL.md 中声明权限边界

```markdown
## 权限说明
**文件访问**：读取上传目录；写入输出目录
**网络访问**：无（本 Skill 不访问任何外部网络）
**不会进行的操作**：不读取系统文件、不修改原始文件、不访问外部服务
```

## 三、防止路径穿越攻击

脚本接受用户提供的路径时，验证 realpath 是否在允许范围内：

```python
def is_safe_path(path, allowed_dirs) -> bool:
    real_path = os.path.realpath(os.path.abspath(path))  # 消除 .. 和符号链接
    for allowed in allowed_dirs:
        real_allowed = os.path.realpath(allowed)
        if real_path.startswith(real_allowed + os.sep) or real_path == real_allowed:
            return True
    return False

def safe_read_path(user_input):
    if not is_safe_path(user_input, ALLOWED_READ_DIRS):
        raise PermissionError(f"拒绝访问：{user_input}，只允许读取：{ALLOWED_READ_DIRS}")
```

可拦截 `/uploads/../../etc/passwd` 类穿越路径。

## 四、API 密钥安全存储

按优先级从多个来源读取：环境变量 → 本地密钥文件（~/.skill_secrets，KEY=VALUE 每行）→ 找不到且必需则抛异常并给出设置指引。

| 方式 | 安全性 | 推荐程度 |
|---|---|---|
| 硬编码在脚本中 | 极低，会提交到 Git | 禁止 |
| 环境变量 | 中，进程隔离 | 推荐（开发） |
| .env 文件（加入 .gitignore） | 中 | 推荐（本地） |
| 系统密钥管理器（Vault） | 高，集中管理 | 推荐（生产） |

## 五、防止命令注入

用户输入传给 Shell 命令时必须转义：

```python
# ❌ 危险：os.system(f"process {user_input}")   # ; rm -rf / 注入风险！

# ✅ 正确：使用列表参数，subprocess 自动处理转义
cmd = ["python", "scripts/process.py", user_input]
subprocess.run(cmd, capture_output=True, text=True)

# ✅ 必须构建字符串时：shlex.quote 转义
safe_name = shlex.quote(user_filename)
```

> 永远不要用字符串拼接 + shell=True 执行包含用户输入的命令。
