# 组合与编排

> 来源：[Skills 组合与编排](https://www.runoob.com/skills/skills-compose.html)

## 一、组合模式：两种思路

| 模式 | 描述 | 适用场景 |
|---|---|---|
| 顺序编排 | Skill A 的输出作为 Skill B 的输入 | 数据处理流水线 |
| 并行调用 | 同时使用多个 Skill，结果合并 | 多源数据聚合 |

> Claude 单次对话可跨 Skill 调用，但一次只能"主动读取"一个 Skill 的正文。复杂多 Skill 工作流通常由一个**"编排 Skill"**统筹调度。

## 二、顺序编排示例（PDF → Word 摘要报告）

编排 Skill 的 SKILL.md 协调三个阶段：

```markdown
### 阶段一：提取 PDF 文字
使用 pdf-reading Skill 的脚本：
python /mnt/skills/public/pdf-reading/scripts/extract.py \
  --input <pdf路径> --output /home/claude/extracted_text.txt

### 阶段二：生成摘要内容（Claude 自己处理）
生成主题、章节摘要、重要数据 → 写入 summary.json

### 阶段三：生成 Word 报告
使用 docx Skill 的规范：
python /mnt/skills/public/docx/scripts/generate.py \
  --template .../report_template.docx --data summary.json --output report.docx
```

## 四、避免循环依赖

Skill A 依赖 Skill B、B 又依赖 A 时会形成循环依赖导致无法执行。设计组合时保持**单向依赖**关系。
