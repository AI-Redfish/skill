# 外部 API 集成

> 来源：[Skills API 集成](https://www.runoob.com/skills/skills-api-integration.html)

## 一、基本调用模式

用 requests 封装通用调用函数，捕获超时/HTTP 错误/连接错误：

```python
API_KEY = os.environ.get("MY_API_KEY", "")   # 从环境变量读取，不硬编码

def call_api(endpoint: str, payload: dict, timeout: int = 30) -> dict:
    if not API_KEY:
        return {"error": "未设置 API 密钥，请设置环境变量 MY_API_KEY"}
    try:
        response = requests.post(BASE_URL + endpoint,
                                 headers={"Authorization": f"Bearer {API_KEY}"},
                                 json=payload, timeout=timeout)
        response.raise_for_status()
        return response.json()
    except requests.Timeout:      return {"error": f"请求超时（超过 {timeout} 秒）"}
    except requests.HTTPError as e: return {"error": f"HTTP 错误 {e.response.status_code}"}
    except requests.ConnectionError: return {"error": "无法连接到 API 服务，请检查网络"}
```

## 二、API 密钥安全管理

- **永远不要**把密钥硬编码在脚本中（会被提交到 Git）
- 通过环境变量传递：`export MY_API_KEY="sk-xxx"`，永久生效写入 `~/.bashrc`
- 在 SKILL.md 中告知用户需要配置密钥及配置方法
- 用 .gitignore 排除 .env 等密钥文件

密钥管理方式安全等级：硬编码（禁止）< 环境变量 / .env（开发推荐）< 系统密钥管理器如 Vault（生产推荐）。

## 三、处理 API 限速（Rate Limiting）

批量调用时在请求间加入延迟：

```python
class RateLimitedClient:
    def __init__(self, base_url, api_key, requests_per_minute=60):
        self.min_interval = 60.0 / requests_per_minute  # 每次请求最小间隔

    def _wait_if_needed(self):
        elapsed = time.time() - self.last_request
        wait = self.min_interval - elapsed
        if wait > 0: time.sleep(wait)

    def post(self, endpoint, payload):
        self._wait_if_needed()
        resp = requests.post(...)
        if resp.status_code == 429:          # Too Many Requests
            retry_after = int(resp.headers.get("Retry-After", 5))
            time.sleep(retry_after)
            resp = requests.post(...)         # 重试一次
        ...
```

## 四、响应结果缓存

相同输入返回相同结果的 API，缓存到本地文件避免重复请求（省钱提速）：

```python
def _cache_key(endpoint, payload) -> str:
    raw = json.dumps({"endpoint": endpoint, "payload": payload}, sort_keys=True)
    return hashlib.md5(raw.encode()).hexdigest()

def cached_call(endpoint, payload, call_fn):
    cache_file = os.path.join(CACHE_DIR, f"{_cache_key(endpoint, payload)}.json")
    if os.path.exists(cache_file):            # 命中缓存
        return json.load(open(cache_file))
    result = call_fn(endpoint, payload)
    if "error" not in result:                 # 只缓存成功结果
        json.dump(result, open(cache_file, "w"), ensure_ascii=False)
    return result
```
