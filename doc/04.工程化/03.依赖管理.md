## 一、依赖声明文件

在 scripts/ 下集中声明依赖，锁定版本确保可重复安装：

**Python — requirements.txt：**
```
pandas==2.1.4         # 数据处理
openpyxl==3.1.2       # Excel 读写
pypdf==3.17.0         # PDF 处理
requests==2.31.0      # HTTP 请求
```

**Node.js — package.json：**
```json
{
  "name": "my-skill-scripts",
  "dependencies": { "xlsx": "^0.18.5", "puppeteer": "^21.0.0" }
}
```

## 二、在 SKILL.md 中说明安装方式

```markdown
## 依赖安装
首次使用前，运行以下命令安装 Python 依赖：
pip install -r scripts/requirements.txt --break-system-packages
若运行环境已预装依赖，可跳过此步骤。
```

## 三、脚本自动安装依赖

```python
DEPENDENCIES = [
    ("pandas", "pandas", ">=2.0"),       # (pip安装名, import名, 版本要求)
    ("python-docx", "docx", None),
]

def install_if_missing(pip_name, import_name):
    try:
        importlib.import_module(import_name)
        return True                        # 已安装
    except ImportError:
        result = subprocess.run(
            [sys.executable, "-m", "pip", "install", pip_name,
             "--break-system-packages", "--quiet"],
            capture_output=True, text=True)
        return result.returncode == 0
```

适合零配置运行的 Skill。

## 四、版本冲突处理策略

| 策略 | 做法 | 适用场景 |
|---|---|---|
| 宽松版本要求 | 用 `>=` 而非 `==` | 大多数场景，兼容性好 |
| 虚拟环境 | venv 中安装，与系统隔离 | 对版本有严格要求 |
| 使用系统已有版本 | 不锁定版本 | 常用库且版本差异影响小 |

虚拟环境主要用于**本地开发阶段**（避免与开发机其他项目冲突）；Claude 执行环境每次会话相对隔离，通常不需要。

