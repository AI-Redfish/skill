# 调试与日志

> 来源：[Skills 调试](https://www.runoob.com/skills/skills-debug.html) / [Skills 日志与调试进阶](https://www.runoob.com/skills/skills-debug-advanced.html)

## 一、三类常见问题

| 问题类型 | 现象 | 优先排查点 |
|---|---|---|
| 未触发 | 完全没有使用 Skill | description 写法、任务复杂度 |
| 触发但执行错误 | Skill 被读取但脚本运行失败 | 脚本路径、依赖、参数格式 |
| 触发且执行但结果不对 | 输出与期望有出入 | SKILL.md 指令清晰度 |

## 二、问题一：Skill 未触发

1. **确认文件被正确加载**：目录结构正确，SKILL.md 存在且非空
2. **检查 YAML frontmatter 格式**：必须以 `---` 开始结束；字段名无多余空格；冒号后必须有一个空格
3. **用更复杂的测试提示词**：

| 不易触发 | 更易触发 |
|---|---|
| "分析这个文件" | "分析这份销售数据 CSV，找出月度增长趋势，生成统计摘要表格" |
| "生成一个 PPT" | "根据这份报告，创建一个 10 页的产品介绍演示文稿，要有图表和摘要" |

## 三、问题二：脚本执行错误

让 Claude 直接运行脚本并查看输出，常见错误：

| 错误信息 | 原因 | 修复方法 |
|---|---|---|
| ModuleNotFoundError | 依赖未安装 | pip install 包名 |
| FileNotFoundError | 文件路径错误 | 检查上传目录 |
| PermissionError | 无写入权限 | 输出目标改为输出目录 |
| SyntaxError | 语法错误 | `python -m py_compile 脚本.py` 检查 |

快速语法检查：

```bash
python -m py_compile scripts/process.py && echo "语法正确" || echo "语法错误"
bash -n scripts/run.sh && echo "语法正确"
```

## 四、问题三：输出不符合预期

- 在 SKILL.md 中临时添加调试输出指令（识别到的输入、期望格式、计划步骤，确认后继续），发布前删除
- 消除指令歧义：
  - ❌ "处理完成后输出结果" → ✅ "将结果保存到输出目录，并在对话中展示文件路径"
  - ❌ "分析数据" → ✅ "计算各列的均值、中位数、标准差，以 Markdown 表格输出"

## 五、print 调试

关键节点加 `[DEBUG]` 打印，完成后删除，避免正式输出混入调试信息。

## 六、进阶：用 logging 替代 print

控制输出级别——开发时 DEBUG，生产时只输出 WARNING 以上：

```python
def get_logger(name, level="INFO"):
    logger = logging.getLogger(name)
    # console handler: "[%(asctime)s] [%(levelname)s] %(name)s - %(message)s"
    # file handler: 写入日志文件
```

## 七、执行时间追踪

用装饰器或上下文管理器找耗时瓶颈：

```python
@timeit
def load_csv(file_path): ...

with Timer("读取并清洗数据"):
    ...
# 输出：load_csv 耗时 0.342 秒
```

## 八、结构化 JSON 日志

日志需要被程序解析时输出 JSON，**输出到 stderr** 避免与正常输出混合：

```python
def log_event(level, event, **context):
    entry = {"timestamp": ..., "level": level, "event": event, **context}
    print(json.dumps(entry, ensure_ascii=False), file=sys.stderr)

log_event("warning", "null_detected", column="score", count=12)
```

## 九、SKILL.md 指令执行调试（检查点）

在 SKILL.md 中插入临时检查点：

```markdown
## 调试检查点（发布前删除）
执行每个步骤前输出：[STEP N] 开始：{步骤名称}，输入：{关键参数}
```

## 十、调试场景速查表

| 场景 | 调试方法 |
|---|---|
| Skill 未触发 | 检查 description、用复杂提示词测试、run_loop 优化 |
| ImportError | pip install，检查包名与 import 名是否匹配 |
| 文件路径报错 | 先 ls 确认文件名 |
| 输出乱码 | 读取文件时显式 encoding="utf-8" |
| 步骤顺序不对 | SKILL.md 用编号列表明确顺序 |
| 结果为空 | 关键节点加 print，确认数据在哪步变空 |
