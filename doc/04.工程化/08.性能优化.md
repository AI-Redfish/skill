# 性能优化

> 来源：[Skills 性能优化](https://www.runoob.com/skills/skills-performance.html)

## 一、性能问题的常见来源

| 来源 | 典型表现 | 优化方向 |
|---|---|---|
| 一次性加载大文件 | 读 100MB CSV 耗时数秒 | 分块读取（chunk） |
| 重复执行相同计算 | 每次调用重新算统计值 | 缓存结果 |
| 单线程串行处理 | 处理 1000 个文件很慢 | 并行处理 |
| 频繁磁盘 I/O | 循环逐行写入 | 批量写入 |
| 不必要的依赖加载 | import 耗时 2 秒+ | 延迟导入 |

## 二、大文件分块读取

pandas `chunksize` 逐块处理，避免一次性占满内存，并实时汇报进度：

```python
for chunk in pd.read_csv(file_path, chunk_size=10000):
    total_rows += len(chunk)
    if "score" in chunk.columns:
        total_sum += chunk["score"].sum()
    print(f"  已处理第 {chunk_count} 批，累计 {total_rows} 行", flush=True)
```

## 三、结果缓存

相同输入相同结果的操作，按**文件指纹**（路径+大小+mtime，比 MD5 内容快得多）缓存：

```python
def _file_fingerprint(file_path):
    stat = os.stat(file_path)
    return hashlib.md5(f"{file_path}|{stat.st_size}|{stat.st_mtime}".encode()).hexdigest()

# get_cached() / set_cached()：以 指纹+操作名 为键存取 JSON
```

## 四、并行处理多个文件

```python
with concurrent.futures.ThreadPoolExecutor(max_workers=4) as executor:
    future_map = {executor.submit(process_single_file, fp): fp for fp in file_paths}
    for future in concurrent.futures.as_completed(future_map):
        result = future.result()
```

> max_workers 默认 4，避免过多进程争抢资源。

## 五、优化核查清单

| 检查项 | 优化前 | 优化后 |
|---|---|---|
| 读取大文件 | pd.read_csv(file) | pd.read_csv(file, chunksize=10000) |
| 重复统计同一文件 | 每次重新计算 | 文件指纹缓存 |
| 处理多个文件 | for 循环串行 | ThreadPoolExecutor 并行 |
| 逐行写入文件 | for row: f.write(row) | 批量收集后一次写入 |
| 不必要的 import | 顶部全部 import | 用到时再 import（延迟导入） |

> **优化前先测量**。用 time.perf_counter() 或 @timeit 找出真正瓶颈再有针对性优化，避免过早优化带来不必要的复杂度。
