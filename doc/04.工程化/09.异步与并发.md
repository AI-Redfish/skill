# 异步与并发

> 来源：[Skills 异步与并发](https://www.runoob.com/skills/skills-async.html)

## 一、同步 vs 异步：何时该用异步

| 场景 | 推荐方式 | 原因 |
|---|---|---|
| 单个文件处理、单次 API 调用 | 同步 | 异步收益不明显，代码更简单 |
| 同时发出多个 HTTP 请求 | 异步 | 总时间 ≈ 最长单次时间 |
| 同时读取多个文件 | 异步或线程池 | I/O 等待时可切换任务 |
| CPU 密集型计算（图像处理等） | 多进程 | asyncio 不绕过 GIL |

> 异步 ≠ 并行。asyncio 是单线程事件循环，适合 **I/O 密集型**任务；CPU 密集型用 ProcessPoolExecutor。

## 二、异步并发 HTTP 请求（aiohttp）

同步串行 3 次请求 ≈ 三次耗时之和；异步并发 ≈ 最慢那一次（可省约 65% 时间）：

```python
async def fetch_one(session, endpoint, payload):
    async with session.post(url, json=payload, headers=headers,
                            timeout=aiohttp.ClientTimeout(total=30)) as resp:
        resp.raise_for_status()
        return {"endpoint": endpoint, "status": "ok", "data": await resp.json()}

async def fetch_all(requests):
    async with aiohttp.ClientSession() as session:
        tasks = [fetch_one(session, ep, pl) for ep, pl in requests]
        # gather 并发执行；return_exceptions=True 防止一个失败影响其他
        return await asyncio.gather(*tasks, return_exceptions=True)

results = asyncio.run(fetch_all(requests))
```

## 四、超时控制与任务取消

`asyncio.wait_for` 为单个任务设置最大等待时间：

```python
try:
    result = await asyncio.wait_for(coro, timeout=2.0)
    results[name] = {"status": "ok", "result": result}
except asyncio.TimeoutError:
    results[name] = {"status": "timeout", "message": "超过 2 秒未完成"}
```
