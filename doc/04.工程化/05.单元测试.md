# 单元测试

> 来源：[Skills 单元测试](https://www.runoob.com/skills/skills-testing.html)

## 一、测试的两个层次

| 层次 | 测试对象 | 方法 |
|---|---|---|
| 脚本单元测试 | scripts/ 下的 Python/JS 脚本 | pytest / unittest |
| 触发端到端测试 | Skill 是否被正确触发、输出是否符合预期 | skill-creator 的 eval 框架 |

## 二、脚本单元测试（pytest）

覆盖正常情况、边界情况、集成（真实文件）：

```python
# scripts/tests/test_clean_data.py
def test_remove_duplicates_basic():
    rows = [{"name": "runoob", "score": "90"},
            {"name": "runoob", "score": "90"},   # 重复行
            {"name": "RUNOOB", "score": "80"}]
    result = remove_duplicates(rows)
    assert len(result) == 2

def test_remove_duplicates_empty():      # 边界：空列表不报错
    assert remove_duplicates([]) == []

def test_fill_nulls_numeric():           # 空值填充
    result = fill_nulls([{"value": "10"}, {"value": ""}], col="value", fill_with="0")
    assert result[1]["value"] == "0"

def test_process_real_file():            # 集成：临时 CSV 文件全流程
    ...
```

运行：

```bash
cd my-skill/
pytest scripts/tests/ -v                              # 运行全部
pytest scripts/tests/ --cov=scripts --cov-report=term-missing   # 覆盖率
```

## 三、触发端到端测试

验证用户发出请求时 Claude 是否会使用这个 Skill。测试用例 JSON 定义：

```json
[
  {
    "id": "trigger_basic",
    "prompt": "帮我分析这份销售数据 CSV，找出月度趋势并生成统计摘要",
    "assertions": [
      {"type": "skill_triggered", "skill": "csv-analyzer"}
    ]
  },
  {
    "id": "no_trigger_simple",
    "prompt": "CSV 是什么格式？",
    "assertions": [
      {"type": "skill_not_triggered", "skill": "csv-analyzer",
       "description": "简单知识问题不应触发 Skill"}
    ]
  }
]
```

断言类型：`skill_triggered` / `skill_not_triggered` / `output_contains`。

运行（需要 skill-creator 的 eval 工具）：

```bash
python -m scripts.run_eval \
  --eval-set evals/trigger-eval.json \
  --skill-path csv-analyzer/ \
  --model claude-sonnet-4-20250514

# 生成 HTML 报告供人工审阅
python eval-viewer/generate_review.py --results evals/results/ --output evals/review.html
```

> 测试提示词要足够复杂。简单的"读取 CSV"即使触发失败也不代表 Skill 有问题（Claude 本身就能处理）。好的测试用例是用户真实会提的**多步骤、有明确输出要求**的请求。

## 四、测试用例覆盖范围

| 类型 | 要覆盖的场景 |
|---|---|
| 正向触发 | 复杂任务、包含关键词、明确输出格式要求 |
| 负向触发 | 简单问答、提到相关词但不需要 Skill |
| 边界输入 | 空文件、超大文件、格式不支持的文件 |
| 错误恢复 | 文件路径错误时提示是否清晰 |
