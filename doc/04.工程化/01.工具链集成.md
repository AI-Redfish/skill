# 工具链集成

> 来源：[Skills 与工具链集成](https://www.runoob.com/skills/skills-toolchain.html)

## 一、可调用的工具类型

| 工具类型 | 示例 | 调用方式 |
|---|---|---|
| 系统命令 | ls、cp、find、wc | subprocess.run() |
| 语言运行时 | python、node、bash | subprocess.run() |
| 文档处理工具 | pandoc、pdflatex | subprocess.run() |
| 媒体处理工具 | ffmpeg、imagemagick | subprocess.run() |
| Python 库 | pandas、openpyxl、pypdf | import 后直接调用 |
| Node.js 工具 | prettier、eslint | npx 调用 |

> 调用前先确认工具已安装。沙箱通常预装 python3、pip、node、npm；pandoc、ffmpeg 等需额外安装。

## 二、标准命令调用封装

```python
def run_command(cmd: list, timeout: int = 60) -> dict:
    try:
        result = subprocess.run(cmd, capture_output=True, text=True, timeout=timeout)
        return {
            "success": result.returncode == 0,
            "returncode": result.returncode,
            "stdout": result.stdout.strip(),
            "stderr": result.stderr.strip()
        }
    except FileNotFoundError:
        return {"success": False, "stderr": f"命令不存在：{cmd[0]}，请确认已安装"}
    except subprocess.TimeoutExpired:
        return {"success": False, "stderr": f"命令执行超时（超过 {timeout} 秒）"}
```

## 三、执行前检查工具可用性

```python
import shutil
for tool, install_cmd in REQUIRED_TOOLS:
    path = shutil.which(tool)      # 在 PATH 中查找
    if path: print(f"  已安装：{tool} → {path}")
    else:   print(f"  未安装：{tool}  安装命令：{install_cmd}")
```

在任务中途失败前给出清晰提示。

## 四、在 SKILL.md 中声明工具依赖

用 frontmatter 的 compatibility 字段：

```yaml
compatibility:
  tools:
    - pandoc >= 2.14
    - python >= 3.8
  python_packages:
    - pypdf >= 3.0
    - python-docx >= 1.0
```

## 五、Node.js 工具集成

```python
subprocess.run(["npx", "--yes", "prettier", "--write", file_path], ...)
```

`npx --yes` 首次运行自动下载工具包，需网络。网络受限环境应提前 `npm install -g`。

## 六、工具输出标准化

| 处理方式 | 适用场景 | 典型工具 |
|---|---|---|
| 捕获 stdout | 结果输出到标准输出 | pandoc、wc、cat |
| 检查返回码 | 成功 0 失败非 0 | 几乎所有 CLI |
| 读取输出文件 | 结果写入指定文件 | ffmpeg、pandoc -o |
| 解析 JSON 输出 | 工具支持 --json | eslint --format json |

## 七、完整示例流程（Markdown → PDF）

标准工作流：**检查工具 → 验证输入 → 调用 pandoc → 确认输出**

```python
# 1. check_pandoc(): shutil.which("pandoc") 检查
# 2. validate_input(): 文件存在 + 扩展名 .md
# 3. convert_to_pdf():
subprocess.run([
    "pandoc", md_path,
    "-o", output_path,
    "--pdf-engine=xelatex",       # 支持中文
    "-V", "CJKmainfont=SimSun",
    "-V", "geometry:margin=2cm"
], capture_output=True, text=True, timeout=120)
# 4. 输出 JSON：{"status": "success", "output": "...", "size_kb": 248}
```

输出文件名带时间戳避免覆盖旧文件；SKILL.md 中根据 status 决定展示文件还是展示错误信息。
