# 实战项目三：多 Skill 协作工作流

> 来源：[多 Skill 协作工作流](https://www.runoob.com/skills/skills-project-multi.html)
> 目标：掌握多 Skill 编排，设计统筹全局的编排 Skill

## 一、工作流目标

用户上传一份业务数据文件，系统自动完成全链路工作，交付完整业务报告：

```
用户上传文件（.csv/.xlsx）
  → 数据清洗（data-cleaner）
  → 摘要生成（doc-summarizer）
  → 报告输出（Excel + 摘要）
  → 交付用户（present_files）
```

## 二、编排 Skill 的设计原则

编排 Skill **不做具体业务处理**，只负责调度：

| 编排 Skill 做的事 | 编排 Skill 不做的事 |
|---|---|
| 按顺序调用子 Skill 的脚本 | 重复实现子 Skill 已有的功能 |
| 在步骤间传递文件路径 | 直接操作数据内容 |
| 向用户汇报整体进度 | 关注单个步骤的内部细节 |
| 处理步骤失败后的补救逻辑 | 捕获子 Skill 内部的异常 |

def run(script_path, *args) -> dict:
    """运行指定脚本，返回 JSON 结果"""
    result = subprocess.run([sys.executable, script_path] + list(args),
                            capture_output=True, text=True, timeout=120)
    try:
        return json.loads(result.stdout)
    except json.JSONDecodeError:
        return {"status": "error", "message": result.stderr or "脚本无输出"}

要点：
- 每阶段实时输出进度（`【1/3】...`，flush=True）
- 任一阶段失败立即返回 `{stage, message}`，**不继续后续阶段**
- 完成后清理临时工作目录

## 四、编排 Skill 的 SKILL.md

```markdown
---
name: report-pipeline
description: >
  完整的数据报告生成流水线：自动对上传的 CSV/Excel 文件执行数据清洗、
  统计分析并生成 Excel 报告。当用户需要一键生成数据报告、
  从原始数据直接输出分析报告时触发。
---

## 前置条件
需要以下 Skills 已安装：data-cleaner v1.0+

## 执行
python scripts/orchestrator.py <上传文件路径>
解析 JSON 输出后调用 present_files 展示报告文件。

## 失败处理
若任意阶段失败，输出包含 stage 和 message 的错误信息，
告知用户哪个阶段失败及可能原因，不要继续执行后续阶段。
```
