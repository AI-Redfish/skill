# 实战项目一：代码审查 Skill

> 来源：[Skill 代码审查](https://www.runoob.com/skills/skills-project-code-review.html)
> 目标：掌握工具链集成与结构化问题报告的生成

## 一、需求分析

| 功能 | 支持语言 | 工具 |
|---|---|---|
| 语法检查 | Python | py_compile（内置） |
| 代码风格检查 | Python | flake8 |
| 代码复杂度分析 | Python | radon |
| JavaScript 检查 | JS/TS | eslint（npx） |
| 综合问题报告 | 所有 | 自定义聚合脚本 |

## 二、目录结构

```
code-reviewer/
├── SKILL.md
└── scripts/
    ├── requirements.txt
    ├── check_python.py
    ├── check_js.py
    └── generate_report.py
```

## 三、核心实现要点（check_python.py）

1. **ensure_tools()**：flake8、radon 未安装时自动 pip install
2. **check_syntax()**：`python -m py_compile` 检查语法
3. **check_style()**：flake8 检查风格，`--max-line-length=100`，解析输出为 `{line, col, code, message}` 列表
4. **check_complexity()**：radon cc 分析，只返回复杂度等级 C 以上（复杂度 > 10）的函数
5. **review_python()**：汇总并计算评级
   - 语法错误 → F
   - error 数 > 10 → C；> 3 → B；否则 → A

输出 JSON：

```json
{
  "status": "success", "file": "runoob_app.py", "grade": "B",
  "syntax_ok": true,
  "style_issues": [{"line": 12, "code": "E302", "message": "expected 2 blank lines"}],
  "error_count": 3, "warning_count": 2, "complex_functions": []
}
```

## 四、SKILL.md 设计

```markdown
---
name: code-reviewer
version: 1.0.0
description: >
  自动审查用户上传的代码文件，检查语法错误、风格问题和代码复杂度，
  生成带评级的问题报告并给出改进建议。当用户需要代码审查、
  检查代码质量、查找 Bug、评估代码规范时触发。
---

## 执行流程
### 第一步：识别代码文件（按扩展名分流 .py / .js / .ts，其他告知不支持）
### 第二步：运行自动化检查（python check_python.py <文件>）
### 第三步：生成并解读报告
1. 总体评级：A（优秀）/ B（良好）/ C（需改进）/ F（语法错误）
2. 问题汇总表格：行号、问题代码、描述
3. Top 3 优先修复项：最严重的 3 个问题 + 修复建议和示例

若文件无问题：给出简短正面评价。
```

## 五、测试

准备故意包含常见问题的样本文件（多 import 同行、函数命名不规范、未使用变量、类名小写等），运行审查验证输出评级和问题列表符合预期。
