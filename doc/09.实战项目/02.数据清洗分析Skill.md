# 实战项目二：数据清洗与分析 Skill

> 来源：[Skill 数据清洗与分析](https://www.runoob.com/skills/skills-project-data.html)
> 目标：掌握 pandas 数据处理流水线与多步骤 Skill 设计

## 一、功能概览

| 步骤 | 操作 | 输出 |
|---|---|---|
| 1. 读取数据 | 支持 CSV、Excel | 行数、列名、数据类型 |
| 2. 质量检测 | 空值、重复行、异常值扫描 | 质量问题报告 |
| 3. 数据清洗 | 去重、填充空值、标准化列名 | 清洗后的 CSV |
| 4. 统计分析 | 均值、中位数、分布 | 统计摘要表格 |
| 5. 生成报告 | 汇总以上结果 | Excel 报告文件 |

## 三、关键实现要点

### load_data.py
- 按扩展名分流 csv / xlsx；**UnicodeDecodeError 时自动回退 GBK 编码**（中文 Windows 常见）
- 中间结果存 `/home/claude/loaded_data.csv` 供后续步骤使用

### quality_check.py
- 空值统计：每列空值数量 + 百分比
- 重复行统计：`df.duplicated().sum()`
- 异常值检测：数值列用 **IQR 方法**（`q1 - 1.5*IQR ~ q3 + 1.5*IQR` 之外为异常）

### clean_data.py
标准清洗四步 + 清洗统计报告：
1. 标准化列名（strip、小写、空格换下划线）
2. 删除完全重复行
3. 数值列空值填 0、字符串列填空串
4. 字符串去首尾空格

输出：`{"rows_after": ..., "dup_removed": ..., "nulls_filled": ...}`

## 四、SKILL.md 设计（交互式流程）

```markdown
---
name: data-cleaner
description: >
  清洗并分析用户上传的 CSV/Excel 数据，包含质量检测、去重、
  空值处理、统计分析和报告生成。当用户需要数据清洗、数据预处理、
  统计分析、数据质量报告时触发。
---

## 执行流程
### 第一步：加载数据 → 告知数据规模和列名
### 第二步：质量检测 → 展示质量报告，
         **询问用户**：按默认规则清洗？还是自定义处理方式？
### 第三步：用户确认后执行清洗 → 告知清洗结果
### 第四步：输出清洗后的文件并展示下载
```

> 设计亮点：清洗前先展示质量报告并**征询用户确认**，而不是直接清洗——把决策权留给用户。
