# 参数传递与输入输出规范

> 来源：[Skills 参数传递与接收](https://www.runoob.com/skills/skills-params.html) / [Skills 输入/输出](https://www.runoob.com/skills/skills-io-spec.html)

## 一、Skills 如何获取参数（隐式参数传递）

Skills 不像函数那样接收显式参数，**整个对话上下文就是参数**：

| 输入来源 | 示例 | 说明 |
|---|---|---|
| 用户当前消息 | "帮我处理这份 PDF" | 最直接的输入 |
| 上传的文件 | report.pdf | 通过路径或内容传入 |
| 历史对话 | 之前讨论过的数据格式 | 上下文中可引用 |
| 系统变量 | 当前日期、工作目录 | 自动感知 |

### 在 SKILL.md 中声明期望输入

```markdown
## 输入要求
用户应提供以下信息（从对话上下文中获取）：
- **文件路径**：已上传 CSV 文件的路径（位于 /mnt/user-data/uploads/）
- **分析目标**（可选）：如"找出空值"、"统计分布"
- **输出格式**（可选）：表格、图表或文字摘要

若上述信息未明确，主动向用户确认后再执行。
```

"输入要求"是写给 Claude 自己看的：据此从上下文提取信息，或在信息不足时追问。

## 二、脚本接收结构化参数

通过命令行参数（argparse）或 stdin 传递，与普通脚本一致：

```python
parser = argparse.ArgumentParser(description="CSV 文件分析脚本")
parser.add_argument("file", help="必填：CSV 文件路径")
parser.add_argument("--col", help="可选：指定分析的列名")
parser.add_argument("--limit", type=int, default=10, help="可选：最多显示的行数")
```

SKILL.md 中的调用写法：

```bash
python scripts/analyze.py <文件路径> [--col <列名>] [--limit <行数>]
```

### 文件路径处理规范

- 用户上传文件统一位于 `/mnt/user-data/uploads/`
- 脚本中**始终使用绝对路径**，避免相对路径因工作目录不同而失败
- 执行前验证：路径是否提供、文件是否存在、扩展名是否支持、大小是否超大

## 三、输入规范的四个要素

| 要素 | 说明 | 示例 |
|---|---|---|
| 输入类型 | 文件、文本、URL、参数等 | 用户上传的 PDF 文件 |
| 格式要求 | 扩展名、编码、结构 | .csv、UTF-8、第一行为表头 |
| 必填/可选 | 哪些输入必须 | 文件路径必填，列名可选 |
| 缺省行为 | 可选参数未提供时 | 未指定列名时分析所有列 |

示例：

```markdown
## 输入规范
### 必填输入
- **数据文件**：.csv 或 .xlsx 文件，UTF-8 编码，第一行为列标题，不超过 50MB
### 可选输入
- **目标列**：默认分析所有数值列
- **输出格式**：table / text，默认 table
### 输入缺失时的处理
- 文件未上传 → 告知"请上传需要分析的文件"
- 格式不支持 → 列出支持的格式列表
```

## 四、输出规范的三个维度

1. **输出内容**：明确输出什么，避免遗漏或过度输出（如：统计摘要表格 + 数据质量报告 + 文件路径）
2. **输出格式与存储**：

| 输出目标 | 格式 | 存储路径 |
|---|---|---|
| 对话中展示 | Markdown 表格、代码块 | 无需存储 |
| 可下载文件 | .xlsx、.pdf、.html | /mnt/user-data/outputs/ |
| 中间结果 | JSON、CSV | 临时目录 |

3. **输出时机**：读取后立即报基本信息 → 耗时操作先输出进度 → 完成后输出完整结果 → 文件生成后展示路径

## 五、脚本层面的 JSON 输入输出约定

脚本统一返回包含 `status` 字段的 JSON，便于 Claude 稳定解析：

```python
return {"status": "success", "data": {"word_count": len(content), "summary": summary}}
return {"status": "error", "error": f"文件不存在：{file_path}"}

print(json.dumps(result, ensure_ascii=False, indent=2))
```

> 用 JSON 而非自由文本输出，Claude 不需要对文本做猜测性解读。
