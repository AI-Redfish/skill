# Skill 基本结构

> 来源：[Skills 基本结构](https://www.runoob.com/skills/skills-structure.html)

## 一、核心本质

Skills 是给 AI 制定**标准化执行流程**的操作指引，规则一经编写完成，就能像程序函数一样被反复调用、直接复用。

- 以 Markdown 文本为载体存储，本身不直接执行功能
- 按需加载、渐进式调用，高效沉淀工作经验

## 二、核心结构

Skills 的核心就是：**一个文件夹 + 一个 SKILL.md 文件**。

```
my-skill/
└── SKILL.md   （唯一必需）
```

SKILL.md 分为两部分：用 `---` 包裹的 **YAML frontmatter**（头部配置）+ **Markdown 正文**（执行说明）。

```markdown
---
name: your-skill-name
description: 一句话描述该 Skill 的功能和使用场景
---

# Skill 名称

## 使用指引
[给 AI 的分步骤行为指引]

## 示例
[该 Skill 的具体使用示例]
```

## 三、Frontmatter 必填字段

| 字段 | 必填 | 说明 |
|---|---|---|
| name | 是 | 唯一标识符，kebab-case，会被 `/` 命令引用 |
| description | 是 | 一句话描述功能与触发场景，越具体触发越准确 |

### name 命名规范

最多 64 字符，只能小写字母、数字和连字符。推荐**动名词形式**（动词 + -ing）：

```
name: processing-pdfs        # 好：动名词形式，清晰描述功能
name: analyzing-spreadsheets # 好：一眼知道用途

name: helper      # 差：太模糊
name: MySkill     # 差：包含大写
name: data files  # 差：包含空格
```

| 推荐 | 不推荐 | 原因 |
|---|---|---|
| code-reviewer | CodeReviewer | 统一小写和连字符，跨平台兼容 |
| sql-optimizer | sql_optimizer | kebab-case 与目录名一致 |
| deploy-check | deploy-check-tool-v2 | 版本信息放内部说明 |

### description 要求

启动时系统只预加载 name 和 description，只有 description 被判断与任务相关时才读取完整内容。应同时包含：**做什么 + 什么时候用**。

| 推荐 | 不推荐 | 原因 |
|---|---|---|
| 「扫描 Python 代码中的 SQL 注入风险并给出修复建议」 | 「一个安全工具」 | 笼统描述无法准确触发 |
| 「将 Markdown 转换为符合品牌规范的 HTML 邮件」 | 「转换文件格式」 | 缺少场景会被误触发 |

## 四、全部元数据字段

| 字段 | 必需 | 说明 |
|---|---|---|
| name | 是 | 最长 64 字符，小写字母/数字/`-`，不能以 `-` 开头结尾 |
| description | 是 | 最长 1024 字符，不能为空 |
| license | 否 | 许可证名称或指向 bundled 许可证文件 |
| compatibility | 否 | 最长 500 字符，环境与依赖说明（产品、系统包、网络权限） |
| metadata | 否 | 自定义键值对（作者、版本号等） |
| allowed-tools | 否 | 空格分隔的预批准工具列表（实验性） |

示例：

```yaml
---
name: pdf-processing
description: 从 PDF 中提取文本和表格，填写表单，并合并文档
license: Apache-2.0
metadata:
  author: example-org
  version: "1.0"
---
```

## 五、完整目录结构（可选扩展）

为避免上下文膨胀，遵循分工原则：**核心规则 → SKILL.md；详细资料 → 单独文件；实用逻辑 → 脚本执行（不加载）**。

```
my-skill/
├── SKILL.md          # 必需：元数据 + 指令
├── scripts/          # 可选：可执行代码
├── references/       # 可选：参考文档
└── assets/           # 可选：模板、图片等静态资源
```

详见 [02.Skill目录结构](02.Skill目录结构.md)。
