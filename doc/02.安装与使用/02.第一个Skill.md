# 第一个 Skill（Claude Code 实战）

> 来源：[第一个 Skill](https://www.runoob.com/skills/skills-first.html)

## 一、创建 Skill 目录

Skills 存放在 `~/.claude/skills/`（个人全局）或项目目录下 `.claude/skills/`（项目专用）。

```bash
mkdir claude-test && cd claude-test
mkdir -p .claude/skills/python-naming-standard
```

## 二、编写 SKILL.md

在目录下创建 SKILL.md（Skill 的大脑，告诉 Claude 什么时候用它）：

```markdown
---
name: Python 内部命名规范技能
description: 当用户要求重构、审查或编写 Python 代码时，请参考此规范。
---

## 指令
1. 所有的内部辅助函数必须以 `_internal_` 前缀命名。
2. 如果发现不符合此规则的代码，请自动提出修改建议。
3. 在执行 `claude commit` 前，必须检查此规范。

## 参考示例
- 正确：`def _internal_calculate_risk():`
- 错误：`def _calculate_risk():`
```

字段要求：
- **name**：仅小写字母、数字和连字符（最多 64 字符）
- **description**：简要描述及使用时机（最多 1024 字符）

## 三、项目文件结构

```
my-project/
├─ src/test.py                 # 项目源码
├─ .claude/
│  ├─ skills/
│  │  └─ hello-world/
│  │     ├─ SKILL.md           # Skill 定义（YAML + Instructions）
│  │     └─ README.md          # 人类阅读的说明（可选）
│  └─ config.yml               # Claude 项目级配置（可选）
└─ README.md
```

## 四、测试

启动 `claude`，输入任务：

```
帮我写一个计算用户折扣的函数
```

Claude 扫描已安装 Skills，发现请求涉及"Python 代码编写"，匹配 python-naming-standard，生成符合规范的代码：

```python
def _internal_get_discount(user_score):

```

## 五、添加资源文件（可选）

在 Skill 目录下可添加：

- `examples/`：示例文件
- `references/`：参考文档
- `scripts/`：可执行脚本（如 Python 处理 PDF）

然后在 SKILL.md 中引用：

```markdown
查看示例 commit：./examples/good-commit.txt
运行脚本：使用工具执行 ./scripts/process.py
```
