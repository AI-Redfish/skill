# VS Code 中创建与使用 Skill

> 来源：[VS Code Skills](https://www.runoob.com/skills/vs-code-skill.html)

## 一、环境要求

- 安装 VS Code
- 安装 GitHub Copilot 扩展

Agent Skills 是开放格式，相同 Skill 也可用于 Claude Code、OpenCode、OpenAI Codex 等工具。

## 二、创建 Skill（掷骰子示例）

VS Code 默认在项目 `.agents/skills/` 目录查找 Skill：

```bash
mkdir -p .agents/skills/roll-dice
```

创建 `.agents/skills/roll-dice/SKILL.md`：

```markdown
---
name: roll-dice
description: 使用随机数生成器掷骰子。当用户要求掷骰子（d6、d20 等）或生成随机骰子点数时使用。
---

# 掷骰子方法

使用以下 shell 命令生成 1 到指定面数之间的随机数：

## macOS / Linux
​```bash
echo $((RANDOM % <sides> + 1))
​```

## Windows PowerShell
​```powershell
Get-Random -Minimum 1 -Maximum (<sides> + 1)
​```

**用法说明：** 将 `<sides>` 替换为用户指定的骰子面数（d6→6，d20→20）。
**输出：** 直接返回随机结果数字即可，无需额外解释。
```

一个文件、不到 20 行，就是一个完整的 Skill。

## 三、文件结构解析

- **YAML 头部**：name 必须与文件夹名称完全一致（小写+连字符）；description 是 Agent 决定是否激活的关键字段
- **正文**：Agent 激活后实际遵循的指令。示例中同时提供两个平台的命令，Agent 会根据当前环境自动选择

## 四、测试步骤

1. 用 VS Code 打开项目
2. 打开 Copilot Chat 面板（`Ctrl+Shift+I` / `Cmd+Shift+I`）
3. 选择 **Agent 模式**
4. 输入 `/skills` 确认 roll-dice 出现在列表中
5. 输入 `Roll a d20`，Agent 应自动激活 Skill 并返回 1-20 的随机数

## 五、背后工作过程

1. **发现**：会话开始时扫描 `.agents/skills/`，只读 name 和 description
2. **激活**：用户输入与 description 匹配后，加载完整 SKILL.md 正文
3. **执行**：按正文指令识别平台、替换参数、执行命令并返回结果

## 六、常见问题排查

| 问题 | 可能原因 | 解决方法 |
|---|---|---|
| /skills 列表为空 | SKILL.md 路径不正确 | 确认在 `.agents/skills/roll-dice/SKILL.md`，注意 **SKILL.md 必须大写** |
| Agent 没有运行命令 | 模型工具调用可靠性差异 | 换模型，或更明确地说"帮我掷一个 d20" |
| 命令执行失败 | Shell 环境差异 | 确认终端能正常执行 `$RANDOM` 命令 |
