# 安装与使用现有 Skills

> 来源：[使用现有 Skills](https://www.runoob.com/skills/use-existing-skills.html) / [第一个 Skill](https://www.runoob.com/skills/skills-first.html) + 原有笔记（openskills）整合

## 一、官方市场（Anthropic Skills）

官方仓库：https://github.com/anthropics/skills

覆盖设计、开发、企业办公、全品类文档编辑，多数开源。

### 方式 1：注册为 Claude Code 插件市场

```bash
# 注册市场
/plugin marketplace add anthropics/skills

# 直接安装两类插件
/plugin install document-skills@anthropic-agent-skills
/plugin install example-skills@anthropic-agent-skills
```

> 插件安装的 skills 目录在 `~/.claude/plugins/marketplaces/` 下，安装完成后需重启 Claude Code。

也可以通过 `/plugin` → Browse and install plugins → 选择 anthropic-agent-skills → document-skills / example-skills → Install now。

使用时在指令中提及技能名称即可：
```
使用 PDF 技能提取 path/to/some-file.pdf 文件中的表单字段
创建一个 Agent Skill 的演示文稿
```

### 方式 2：通过 openskills 安装（Cursor 等）

前置条件：Node 20+。

```bash
# 安装 openskills
npm i -g openskills
openskills --version

# 安装官方 skills（项目级 / 全局）
openskills install anthropics/skills
openskills install anthropics/skills --global

# 安装非官方 skills（任意 GitHub 仓库）
openskills install nextlevelbuilder/ui-ux-pro-max-skill

# 本地安装（离线包解压到 .claude/skills 后）
openskills sync
```

安装后会在文件管理区看到 `.claude/skills` 文件夹；运行 `openskills sync` 还可生成 `AGENTS.md`（作为 Cursor 使用 Skills 的指导文件）。

### 方式 3：npx skills 安装

```bash
npx skills add https://github.com/anthropics/skills --skill skill-creator
```

## 二、Skill 存放位置（各工具对比）

| 工具 | Skill 存放位置 |
|---|---|
| Claude Code | `.claude/skills/`（项目）或 `~/.claude/skills/`（全局） |
| VS Code + Copilot | `.agents/skills/` 或 `.github/copilot/` |
| OpenAI Codex | `.codex/skills/` |

格式和文件结构是通用的，只是默认目录不同。
